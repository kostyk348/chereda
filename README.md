# Череда

Формат работы, где единица — **петля обязательства**, а ось — **чей ход**.

Не доска, не очередь, не карточки. Петля — это разговор двоих: заказчик просит,
делающий обещает, объявляет сделанное с доказательством, заказчик признаёт или
возражает. Из этих актов однозначно выводится единственное, что нужно знать:
**чей сейчас ход**.

```bash
череда просить  --case "починить сканер музея" --customer ты --performer forgessa
череда круг    --who forgessa
череда обещать  --id 1 --who forgessa --for 1800
череда сделать  --id 1 --who forgessa --proof "test -f build/ok && echo scanner-ok"
череда принять  --id 1 --who ты
череда проверить
```

## Чем это не доска

| Карточка | Петля |
|---|---|
| статус `todo/doing/done` | **чей ход** — одно значение вместо таксономии |
| есть только исполнитель | **двое**: у заказчика свои обязательства и свои часы |
| `done` = и сделано, и принято | **два разных акта**: объявил ≠ признали |
| принято = галочка | принято = **доказательство**, которое можно перепроверить |
| бэклог — вечный список | петля живёт, пока двоим есть что сказать; **бэклога нет** |
| WIP-лимит ставят в колонке | предел работы = **обещания** (по умолчанию три) |
| молчание = ничего | молчание = **часы тикают** и сигнал идёт выше |
| закрыто = навсегда | приёмку может **отменить реальность** |

## Правила

1. **Ход выводится из акта, а не хранится статусом.** `просит / обещано / возражение` —
   ход делающего; `отказ / объявлено` — ход заказчика; `принято / снято` — хода нет.
2. **Не в свой ход не говорят.** Попытка — отказ команды (код 1).
3. **Отказ и возражение — только с причиной.** Без причины это не акт, а молчание.
4. **«Сделано» без доказательства не принимается.** Доказательство = команда + отпечаток
   вывода (тайминги нормализуются, поэтому `Ran 80 tests in 0.01s` и `… 1.4s` — один
   отпечаток, а `82 tests` — другой).
5. **Часы у каждого хода.** Истёк срок → сигнал на уровень выше (свой контур →
   уровень выше → владелец системы), часы пошли заново; выше третьего сигнал не идёт.
6. **Предел работы — обещания.** Больше трёх обещаний один делающий не берёт: отказ в
   ответ на просьбу, а не «перегрузка» потом.
7. **Приёмку может отменить реальность.** `череда проверить` перезапускает
   доказательства: если команда больше не воспроизводит вывод, петля открывается снова
   с причиной и ходом делающего.

## Проверка

```bash
$ cargo test
test result: ok. 11 passed; 0 failed

$ cargo run -q -- демо
итог: 10 проверок, 0 провалов
```

Живой прогон по CLI (полный цикл, включая отмену приёмки):

```
$ череда просить ... → #1 починить сканер музея — ход forgessa (делающий), осталось 4ч
$ череда обещать ... → осталось 30м
$ череда сделать --proof "test -f ok.txt" → доказательство не прошло: код 1 вместо 0
$ touch ok.txt; череда сделать ... → ход ты (заказчик), осталось 1д
$ череда возразить --who ты --reason "нет теста на пустой ответ" → ход forgessa, осталось 8ч
$ череда принять   → закрыта (принято)
$ череда проверить → доказательства воспроизводятся: приёмки в силе
$ rm ok.txt; череда проверить
  #1: приёмка отменена — доказательство не воспроизвелось: код 1 вместо 0
  реальность открыла 1 петель снова
```

## Чем это поможет — и чем не поможет

**Поможет:**
- исчезает спор о статусах: есть один вопрос — «чей ход»;
- «сделано» больше не равно «принято»: агент не может сам себе закрыть работу;
- обещания конечны (часы) и не бесконечны (предел в три);
- заявление «работает» перепроверяется командой, а не памятью;
- приёмка не вечна: сломалось — петля открылась.

**Не поможет:**
- если заказчик один (а он у нас один), его ход — узкое место; лечится тем, что у его
  хода тоже есть часы, но не отменяется;
- двухактное закрытие требует дисциплины: пропустил `принять` — петля стоит и тикает;
- формат не планирует: оценок и сроков «на будущее» в нём нет вовсе, только часы
  текущего хода;
- для одиночной задачи без второго участника он тяжелее обычного «сделал и сказал».

## Провенанс

- **Фернандо Флорес** — «разговоры действий» (просьба → обещание → объявление →
  признание); он же, работая в CORFO, позвал Стаффорда Бира в Чили.
- **Стаффорд Бир** — алгедОнические часы и эскалация на уровень выше (Cyberstride,
  1972).
- **Русский лад** — возражение не голосуется, а снимается.
- **А. С. Макаренко** — нет постоянного владельца работы: командир на время, отряд
  рассыпается.
- **А. К. Гастев** — «ни одного задания без измерений».
- **Н. Ф. Фёдоров** — закрытие не вечно: след остаётся и открывается снова.

Ноль зависимостей: формат петель — плоский текст `ключ=значение` в каталоге `среда/loops/`.
Ни сервера, ни базы.
